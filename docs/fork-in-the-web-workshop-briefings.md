# Fork in the Web — Workshop Series Briefings

Facilitator and workshop-design agent brief for four **standalone**, **75-minute**, **online** workshops tied to the Desirable Properties Challenge perspective [*A Fork in the Web*](https://staging.desirableproperties.org/perspectives/the-fork-in-the-web).

---

## Design decisions

| Decision | Choice |
|----------|--------|
| Workshop count | **4** — aligned to four movements of the Fork essay (not the five pathway questions) |
| Attendance | **Standalone** — participants may attend any session; no required order |
| Duration | **75 minutes** (hard stop) |
| Format | **Online** (Zoom, Google Meet, or equivalent) |
| Outputs | **Required** — each session produces one submittable artifact |
| Tone | Pro-human, architectural, **not** anti-AI |

### Series arc (suggested order, not required)

| # | Workshop | Core tension |
|---|----------|--------------|
| 1 | The First Fork: You → AI → Everything Else | Convenience vs. direct presence on the Web |
| 2 | Concierge vs. Commons | AI that *feels* interoperable vs. architecture that *is* |
| 3 | Designing the Human-Centered Layered Web | What we build *around* AI, not instead of it |
| 4 | Sovereignty, Subsidiarity & the Second Fork | Rights, operating rules, and “will there still be a human world?” |

**Cadence ideas:** one per week; or **1+3** and **2+4** as two half-days.

---

## Global instructions (workshop-design agent)

You are designing facilitator-ready workshop experiences for the Desirable Properties Challenge.

**Audience:** Mixed — technologists, policymakers, educators, artists, community organizers, DP workgroup members. Assume intelligent non-experts.

**Tone:** Serious, pro-human, non-partisan, architectural (not anti-AI). AI is powerful and welcome; the question is what we build around it.

**Standalone rule:** Each session opens with a 5-minute “where we are in the fork” recap so newcomers need not have attended earlier workshops. Do not assume shared vocabulary beyond: first fork (AI serves humanity) vs. second fork (what kind of Internet that service happens in).

**Online facilitation requirements:**

- Provide a run-of-show with exact minute marks.
- Specify breakout instructions (roles: **facilitator**, **scribe**, **reporter**).
- Specify one shared capture surface per breakout (Google Doc, Miro, Padlet, or similar).
- Use chat + optional poll for plenary (no cold-calling required).
- Cameras optional in plenary; encourage on in breakouts.
- Artifact must be completable in the final ~15 minutes and submittable via a single link/form before participants leave.

**Design principles:**

- Do not design lectures. Design: provocation → small-group sense-making → plenary → concrete artifact.
- Link workshops to Desirable Properties without requiring prior DP expertise.
- Use the assigned illustration as an opening anchor; return to it (or a paired image) at close.

**Standard post-workshop CTA:**

- Discuss on [desirableproperties.org](https://staging.desirableproperties.org)
- Join a [workgroup](https://staging.desirableproperties.org/workgroups/join)
- Invite someone to the next standalone session

## Standalone recap script (5 minutes — every workshop)

Reuse at the start of **each** session:

1. **First fork** ([humanstatement.org](https://humanstatement.org/)): Will AI remain under human control?
2. **Second fork** (*A Fork in the Web*): *What kind of digital world* exists when AI is everywhere?
3. **Two trajectories** (one breath each):
   - **You → AI → Everything Else** — a complex machine world, simple human aperture
   - **Human-centered layered Web** — many independent environments around shared resources
4. **Today’s slice:** *[one sentence — see each workshop below]*

## Workshop 1 — The First Fork: You → AI → Everything Else

**Today’s slice:** “We name what disappears when intelligence replaces place.”

### Purpose

Surface the nested fork inside the Pro-Human AI conversation: not only “will AI serve humanity?” but “what kind of digital world exists when AI is everywhere?”

### Anchor reading

- Fork sections: opening through **Intelligence Is Not a Place**
- [humanstatement.org](https://humanstatement.org/) — first fork only (~5 min pre-read)

### Anchor images

| Role | File (repo path) |
|------|------------------|
| Primary (open) | `challenge-site/public/images/perspectives/the-fork-in-the-web/you-ai-everything-else.webp` |
| Secondary (contrast) | `challenge-site/public/images/perspectives/the-fork-in-the-web/intelligence-is-not-a-place.webp` |

### Central questions

1. What disappears when “You → AI → Everything Else” becomes the default experience?
2. Where do shared places still exist today (URL, forum, archive, classroom, library)?
3. Is “intelligence” the same thing as “place”? What do we lose if we conflate them?

### Run of show (75 min)

| Block | Time | Activity |
|-------|------|----------|
| Welcome + recap | 0–5 | Standalone recap |
| Image provocation | 5–12 | Show *You → AI → Everything Else* → chat: “What is the AI standing between?” |
| Breakout | 12–22 | Rooms of 3–4: “Last time you didn’t open the site — what did you ask AI instead?” |
| Plenary | 22–30 | Stack themes in chat; facilitator reads top 5 |
| Breakout | 30–42 | Pick one need (news, health, purchase, community) → map **AI path** vs **direct-human path** |
| Report back | 42–50 | One reporter per room, ~90 sec |
| **Artifact** | 50–68 | Complete **Human Place Requirements** template |
| Close | 68–75 | Submit link + CTA |

### Primary artifact — Human Place Requirements

| Field | Prompt |
|-------|--------|
| Scenario | The information need we mapped |
| What AI path optimizes for | e.g. speed, personalization |
| What direct-human path preserves | e.g. co-presence, persistence |
| **Must not become only an AI tunnel** | One sentence |
| **Human place requirement** | Pick 2+: persistence · co-presence · contestability · shared memory · provenance |
| Optional DP hook | e.g. DP2, DP8 |

### Related Desirable Properties

- DP2 Participant Agency and Empowerment
- DP4 Data Sovereignty and Privacy
- DP8 Collaborative Environment and Meta-Communities

### Success criteria

Participants can explain both forks and name one experience that requires *place*, not just answers.

## Workshop 2 — Concierge vs. Commons

**Today’s slice:** “We separate brilliant convenience from shared, contestable context.”

### Purpose

Help participants feel the difference between AI that makes fragmentation invisible and architecture that creates shared, contestable context.

### Anchor reading

- Fork sections: **The Privatization of Context**, **We Could Solve the Symptoms Without Solving the Architecture**, **Concierge vs. Commons**

### Anchor images

| Role | File (repo path) |
|------|------------------|
| Open | `challenge-site/public/images/perspectives/the-fork-in-the-web/privatization-of-context.webp` |
| Mid / close | `challenge-site/public/images/perspectives/the-fork-in-the-web/concierge-vs-commons.webp` |

### Central questions

1. What does a brilliant concierge optimize for? What does a commons optimize for?
2. Where does *your* community’s interpretation live tomorrow?
3. When does AI interoperability reduce pressure to fix underlying architecture?

### Run of show (75 min)

| Block | Time | Activity |
|-------|------|----------|
| Welcome + recap | 0–5 | Standalone recap |
| Two images | 5–12 | *Privatization of Context* then *Concierge vs. Commons* — poll: “Which side are we building toward?” |
| Breakout | 12–25 | Facilitator supplies 1-page case (e.g. zoning vote, health guidance, school curriculum): **personalized AI summary** vs **forum thread excerpt** |
| Debrief | 25–32 | Chat: what did the summary hide? what did the thread surface? |
| Role play | 32–45 | Rooms: User · Personal AI · Community member · Dissenting voice — ~3 min each; scribe lists “who was heard without mediation” |
| **Artifact** | 45–68 | **Minimum Viable Commons** one-pager |
| Close | 68–75 | Submit + CTA |

### Facilitator prep

Pre-write the “personalized summary” and “thread excerpt” for the case study so breakouts do not improvise the scenario.

### Primary artifact — Minimum Viable Commons

| Field | Prompt |
|-------|--------|
| Shared resource | URL, document, policy, or event |
| Who can speak for themselves here? | |
| What persists after the session? | |
| Where does dissent accumulate? | |
| What must NOT be only reconstructed by AI? | |
| One-week experiment | Smallest test their community could run |
| Optional DP hook | e.g. DP14, DP22, DP20 |

### Related Desirable Properties

- DP14 Trust and Transparency
- DP22 Civic Memory & Epistemic Continuity
- DP20 Community Ownership

### Success criteria

Participants can say: *“An extraordinarily capable concierge is not a commons.”*

## Workshop 3 — Designing the Human-Centered Layered Web

**Today’s slice:** “We sketch architecture — many worlds around one resource, AI as inhabitant not landlord.”

### Purpose

Move from critique to constructive architecture: many independent environments around shared resources, with AI as inhabitant not landlord.

### Anchor reading

- Fork sections: **A Human-Centered Layered Web**, **The Difference Between a Layer and a Space for Layers**, **AI should be an inhabitant, not the landlord**

### Anchor images

| Role | File (repo path) |
|------|------------------|
| Primary | `challenge-site/public/images/perspectives/the-fork-in-the-web/human-centered-layered-web.webp` |
| Close | `challenge-site/public/images/perspectives/the-fork-in-the-web/ai-inhabitant-not-landlord.webp` |
| Optional | `challenge-site/public/images/perspectives/the-fork-in-the-web/space-for-layers.webp` (layer vs. space for layers) |

### Central questions

1. What sits underneath (substrate) vs. what can exist above and around it?
2. What must be portable (identity, data, context) for plurality to work?
3. What is one *layer* vs. what is *space for layers*?

### Run of show (75 min)

| Block | Time | Activity |
|-------|------|----------|
| Welcome + recap | 0–5 | Standalone recap |
| Diagram walkthrough | 5–15 | Walk *Human-Centered Layered Web* — substrate · environments · identity · protocols · human+AI shared space |
| Breakout build | 15–35 | Pick ONE shared resource (facilitator offers 3: scientific paper, city budget, DP chapter) — sketch **4+ independent environments** around it |
| Protocol brainstorm | 35–45 | Same rooms: what must be **open** (discovery, coexistence, interaction)? |
| Stress test | 45–52 | Plenary: “One AI company owns the only convenient interface” — chat responses |
| **Artifact** | 52–68 | **Layered Web Stack** + draft property paragraph |
| Close | 68–75 | Show *AI Inhabitant Not Landlord* — submit + CTA |

### Primary artifact — Layered Web Stack

```
SUBSTRATE (shared resource): _______________
ENVIRONMENT 1 (who, what activity): _______________
ENVIRONMENT 2: _______________
ENVIRONMENT 3: _______________
ENVIRONMENT 4: _______________
PORTABLE (identity / data / context): _______________
OPEN PROTOCOLS NEEDED: _______________
AI ROLE (inhabitant, not landlord): _______________

DRAFT DESIRABLE PROPERTY (1 paragraph):
“If the Web is to remain human-centered when AI is ubiquitous, then _______________.”

Optional DP hook: DP7, DP8, DP19
```

### Related Desirable Properties

- DP7 Simplicity and Interoperability
- DP8 Collaborative Environment and Meta-Communities
- DP19 Amplifying Presence and Community Engagement

### Success criteria

Participants distinguish **one platform** from **architectural space for many layers**.

## Workshop 4 — Sovereignty, Subsidiarity & the Second Fork

**Today’s slice:** “We turn principles into delegation rules and name what we must still build.”

### Purpose

Convert principles into governance instincts: who holds authority over meaning, where cognitive work should stay, and why human places must persist.

### Anchor reading

- Fork sections: **Intellectual Sovereignty**, **Intellectual Subsidiarity**, **A Pro-Human Internet Requires Human Places**, **The Second Fork in the Road**
- Pathway (skim): [AI & Human Agency](https://staging.desirableproperties.org/pathways/ai-human-agency) — especially *Who remains in control?* and *Who interprets reality?*

### Anchor images

| Role | File (repo path) |
|------|------------------|
| Open | `challenge-site/public/images/perspectives/the-fork-in-the-web/intellectual-sovereignty-subsidiarity.webp` |
| Optional opener | `challenge-site/public/images/perspectives/the-fork-in-the-web/the-fork-in-the-web-hero-draft.webp` |
| Close | `challenge-site/public/images/perspectives/the-fork-in-the-web/second-fork-closing.webp` |

### Central questions

1. **Sovereignty (the right):** Who ultimately holds authority over judgment and meaning?
2. **Subsidiarity (the rule):** Which cognitive tasks should stay with people/communities vs. be delegated to AI?
3. **Second fork:** If AI serves humanity well, will there still be a sufficiently *human* world for it to serve?

**Framing line:** *Intellectual sovereignty is the right. Intellectual subsidiarity is the operating principle.*

### Run of show (75 min)

| Block | Time | Activity |
|-------|------|----------|
| Welcome + recap | 0–5 | Standalone recap |
| Image + frame | 5–12 | *Intellectual Sovereignty & Subsidiarity* — Meaning · Memory · Evidence · Decision at the table; AI pods delegate outward |
| Breakout | 12–28 | **Delegation map** for one scenario (local policy, care decision, classroom, news interpretation) |
| Plenary stress test | 28–38 | “Perfectly truthful intermediary, only gateway” — chat: which rights remain in name only? |
| Human places | 38–48 | Pairs in main room: digital places where people still meet without mandatory AI gate |
| **Artifact** | 48–68 | **Second Fork Statement** packet |
| Close | 68–75 | *Second Fork Closing* image — submit + CTA |

### Primary artifact — Second Fork Statement

| Field | Prompt |
|-------|--------|
| Scenario | |
| **Sovereignty** — who holds authority over meaning? | |
| Tasks that must stay human/community | |
| Tasks rightly delegated to AI | |
| **Subsidiarity rule** (one sentence) | e.g. “Cognitive work stays at the lowest level capable unless delegation clearly increases human capability without transferring agency.” |
| Human place worth defending | Name one |
| **The second fork for me is** | One sentence |
| One action in 7 days | Discuss DP / join workgroup / invite / run mini-experiment |
| Optional DP hook | DP2, DP11, DP12, DP22 |

### Related Desirable Properties

- DP2 Participant Agency and Empowerment
- DP11 Safe and Ethical AI
- DP12 Community-based AI Governance
- DP22 Civic Memory & Epistemic Continuity

### Success criteria

Participants state sovereignty vs. subsidiarity and commit to one concrete next step.

### Facilitator note

End on hope, not doom: the second-fork image shows layered civic spaces we can still build; workshops feed the Challenge, not only critique.
